# Tritonformer

This is a project exploring a vision-transformer implementation using Triton kernels. The primary objectives of this project will be to:
a) Implement Kernels:
	1. LayerNorm
	2. Linear
	3. GeLU
	4. Softmax
b) Fuse Kernels
c) Measure performance tradeoffs of fused operations
d) Implement a training loop and optimizer in Triton
